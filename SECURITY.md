# Security Policy

## Supported Versions

This repository is actively maintained. Security updates are applied to the latest version on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

Please **do not** open public GitHub issues for security vulnerabilities.

Report security issues privately by emailing:

**info@foundationvne.com**

Include as much detail as possible (steps to reproduce, impact, affected components).

We aim to acknowledge reports within **5 business days** and will keep you informed of the progress toward a fix.

Thank you for helping keep Fundación Venezuela Nueva Esperanza and its users safe.
